찾아줘 계정 삭제 요청

탈퇴하면 위치 공유 기록, 가족 그룹 참여 정보를 포함한 회원님의 모든 데이터가 삭제되며 복구할 수 없어요.

방법 1. 앱에서 직접 탈퇴 (즉시 처리)

  1. 찾아줘 앱 실행 후 로그인
  2. 메뉴(≡) > 회원 탈퇴 선택
  3. 안내에 따라 탈퇴 확인

앱 안에서 탈퇴하면 계정과 데이터가 즉시 삭제됩니다.

방법 2. 앱이 없어도 이메일로 요청

기기에 앱이 설치돼 있지 않거나 로그인할 수 없는 경우, 아래 이메일로 가입하신 계정 정보(이메일 또는 가입 방식 — 이메일/구글/카카오)를 알려주시면 확인 후 계정과 데이터를 삭제해드려요.
